# TP2
## Concevoir un site Wordpress pour un club de voyage
 
### Auteur: Hanson Tan
 
La réalisation de ce thème permettra d'optimiser la présentation d'un contenu spécifique sur différentes destinations de vovage populaire et exotiques. Amènra vers divers liens d'agences de voyages aussi.

Pour l'épreuve finale, nous avons ajouter un nouveau template page qui s'appelle pays où on présente les meilleurs destinations des pays. Nous avons ainsi ajouter un menu en utilisant API-Rest pour montrer des pays et une description de chaque destination qui viennent avec. Finalement, on a ajouté une vague pour séparer chaque section de la page.
